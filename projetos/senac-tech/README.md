# Senac Tech

Página responsiva inspirada na referência visual `temp/example.png`, feita com HTML e CSS vanilla.

## Estrutura

```text
senac-tech/
├── README.md
└── web/
    ├── index.html
    ├── css/style.css
    └── assets/img/
```

Abra `web/index.html` diretamente no navegador ou sirva a pasta `web/` com qualquer servidor estático local.

## Conteúdo visual

Cabeçalho com navegação por âncoras, chamada principal, cartões ilustrativos de cursos, seção institucional e rodapé com links. Os cartões e imagens são exemplos substituíveis; não é necessário que coincidam exatamente com a referência.

A página usa Bootstrap Icons via CDN para os ícones e carrega as imagens ilustrativas dos cursos do Unsplash; ambos precisam de conexão com a internet. O logo Senac está incluído localmente. Não há JavaScript.
