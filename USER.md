# Preferências do usuário

Inferidas das solicitações feitas no repositório; atualizar se o usuário corrigir ou complementar.

- Estuda desenvolvimento web, especialmente HTML, CSS e JavaScript vanilla.
- Prefere conversar em português do Brasil.
- Valoriza pragmatismo, concisão, organização técnica e código limpo.
- Prefere soluções enxutas, coesas e reaproveitáveis, sem verbosidade, monólitos ou abstrações desnecessárias.
- Em tarefas de implementação, espera que o assistente examine o contexto e faça mudanças práticas e focadas.
- Valoriza preservar os arquivos de estudo e receber um resumo curto do que mudou.
- Para a página da aula 6, pediu estética inspirada em terminal hacker; é uma preferência visual específica desse trabalho, não necessariamente geral.
